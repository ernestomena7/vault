The one clickable action control — every primary action in Vault is a `primary` Button; everything secondary is `secondary` or `ghost`.

```jsx
<Button variant="primary" icon="upload-cloud">Upload video</Button>
```

Variants: `primary` (accent fill), `secondary` (bordered surface), `ghost` (text-only, for toolbars/rows), `danger` (reject/delete). Sizes `sm`/`md`/`lg`. Supports `loading` (spinner replaces the leading icon) and `disabled`.
